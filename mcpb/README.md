# ednaficator (MCPB Bundle)

Austrian AI Concierge — conversational MCP orchestrator

## Usage

Add to \claude_desktop_config.json\:
\\\json
{
  "mcpServers": {
    "ednaficator": {
      "command": "uv",
      "args": ["run", "--directory", "\D:\Dev\repos", "python", "-m", "ednaficator"],
      "env": { "PYTHONPATH": "\D:\Dev\repos/src" }
    }
  }
}
\\\
